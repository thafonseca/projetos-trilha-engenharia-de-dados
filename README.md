# Trilha de Engenharia de Dados

Repositório de estudos e projetos práticos desenvolvidos ao longo de uma mentoria individual em Engenharia de Dados, com foco na construção de soluções reproduzíveis, qualidade de dados e arquitetura analítica.

## Objetivo

Desenvolver, de forma incremental, conhecimentos e habilidades fundamentais de Engenharia de Dados, desde a modelagem relacional e consultas SQL até a construção de pipelines, arquitetura em nuvem e produtos de dados.

Os projetos utilizam dados sintéticos e priorizam código reproduzível, documentação técnica, validação dos resultados e justificativa das decisões tomadas.

## Projetos da trilha

| Projeto | Tema | Objetivo |
|---|---|---|
| 01 | Banco de dados de contas e transações | Modelar dados relacionais, definir PKs e FKs e desenvolver consultas SQL para analisar movimentações financeiras. |
| 02 | Data Lake e formatos de dados | Explorar as camadas raw e curated, converter CSV para Parquet, aplicar particionamento e comparar armazenamento e desempenho de consultas. |
| 03 | Pipeline incremental e idempotente | Construir um processo de carga incremental que trate novos registros e correções sem gerar duplicidades durante o reprocessamento. |
| 04 | Arquitetura equivalente na AWS | Desenhar uma arquitetura de dados em nuvem utilizando serviços como Amazon S3, AWS Glue, Glue Data Catalog e Amazon Athena, considerando segurança e custos. |
| 05 | Qualidade, incidentes e orquestração | Implementar validações de dados, testes, logs, tratamento de falhas e mecanismos de recuperação e orquestração. |
| 06 | Produto de dados em Data Mesh | Definir um produto de dados com responsáveis, consumidores, contrato, regras de qualidade, SLOs e versionamento. |
| 07 | Projeto integrador e defesa técnica | Integrar os conhecimentos anteriores em uma solução reproduzível, com pipeline, testes, arquitetura documentada e apresentação das decisões técnicas. |
